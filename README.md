# Portfolio — Bhanu Prakash

Freelance portfolio site (Next.js 16 + Tailwind CSS 4).

- Edit all copy in `src/content.ts` (services, projects, experience, FAQ, links).
- Layout is in `src/app/page.tsx`; colors are tokens in `src/app/globals.css` (light + dark).
- Résumé served from `public/Bhanu_Prakash_Resume.pdf`.

```bash
npm install
npm run dev     # http://localhost:3000
npm run build
```

Deploy: push to GitHub and import the repo on Vercel.
